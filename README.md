# Rajwa Nuwayyar's Portfolio

A comprehensive, interactive web portfolio showcasing my skills, projects, and experiences in Software Development, UI/UX Design, IT Support, and Robotics. Built with React and Vite.

## 🚀 Features

- **Interactive Canvas**: Stunning, dynamic background with constellation effects.
- **Robot Lab Simulator**: Interactive 6-DOF robotic arm simulation visualization.
- **Command Palette**: Press `Ctrl+K` (or `Cmd+K`) to open a quick-access terminal-like navigation menu.
- **Cyber Telemetry Dashboard**: Real-time mock stats and terminal outputs.
- **Dynamic Theming**: Support for multiple cyber-themed accents (Cyan, Amber, Violet, Emerald).

## 🛠️ Technologies Used

- **Frontend Framework**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Icons**: [Lucide React](https://lucide.dev/) & Custom SVG Icons
- **Styling**: Modern CSS3 (Variables, Grid, Flexbox, Animations)

## 📦 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16+ recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/RajwaNuwayyar/portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

Start the development server:
```bash
npm run dev
```

### Building for Production

Build the optimized static site:
```bash
npm run build
```
